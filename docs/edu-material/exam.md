# 시험과 강의평가

시험지는 교육자료와 함께 **기본으로 생성**되며, 담당자가 제외를 요청한 경우에만 생성하지
않습니다. 강의평가 설문은 **요청 시 생성**됩니다. 시험 응시, 채점, 수료 처리는 이 탭의 범위
밖이며 화면과 백엔드가 담당합니다.

## 시험 구성

시험 구성(총 문항 수, 유형별 문항 수, 난이도, 요구 메모)은 **구성 계획과 별개의 값**으로
저장됩니다. 구성은 **시험 구성 카드**로 결정하며, 카드 밖의 자유 발화 요구("OX 위주로
15문항")도 구성에 반영됩니다.

- **문항 수** — 총 문항 수를 변경하면 유형별 비율을 유지한 채 재배분합니다.
- **유형** — 객관식, 단답형, O/X, 표 기반 O/X의 유형 구성을 선택합니다.
- **난이도** — 별도로 지정하지 않으면 교육자료의 난이도 설정을 승계합니다.
- **제외** — 시험을 제외하면 구성이 제거되고, **이미 생성된 시험지도 함께 내립니다**.

## 출제 원칙

**출제 재료는 수강자가 받는 자료 본문이 우선입니다.** 자료 본문이 있는 교시는 그
본문에서 출제합니다 — 수강자가 배우지 않은 내용이 시험에 나오는 것을 막기 위한
원칙입니다. 본문이 없는 교시는 채택된 근거 전문으로 대체하고, 본문도 근거도 없는 교시만
출제에서 제외됩니다.

**문항에는 출처 페이지가 기록됩니다.** 각 문항의 출처 페이지는 실제 자료의 교시별 페이지
범위로 검증·보정됩니다.

**표 기반 O/X는 재료를 확인한 뒤 출제합니다.** 출제 재료에 표가 없으면 해당 문항 수를
다른 유형으로 이관하고 그 사실을 보고합니다.

**부족분은 사실대로 보고합니다.** 유형별 요청 수를 채우지 못하면 재생성을 1회 시도하고,
그래도 부족하면 부족분을 그대로 보고합니다. **코드가 문항을 임의로 생성해 채우지 않습니다**.

배점은 총점을 문항 수로 나눠 **균등 배분**합니다.

## 시험지 조판

시험지는 **문항부와 정답·해설부**로 구성된 단일 HTML입니다. 정답·해설부는 인쇄 시 별도
면으로 분리되도록 조판됩니다. 유형별로 답란 형식(객관식 보기, OX 괄호, 단답형 기입란)이
다르게 렌더됩니다.

## 강의평가 설문

강의평가 설문은 요청 시 기본 문항 구성으로 즉시 생성되며, 문항 추가·삭제를 지원합니다.
설문 생성은 평가·결과 탭과 공유하는 **공용 에이전트에 위임**됩니다.
