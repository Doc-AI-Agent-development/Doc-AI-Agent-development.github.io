# 소개

교육자료 생성 탭은 교육 담당자가 **대화만으로** 특정 교육의 교육자료·요약본·시험지·강의평가
설문을 생성하고, 수정하고, 확정하는 기능을 제공합니다. 담당자는 구성과 설정을 항목별로
직접 지정할 수도 있고, **세부 결정 전체를 시스템에 위임**할 수도 있습니다.

## 워크플로

작업은 일반적으로 다음 여섯 단계로 진행됩니다. **단계 순서는 코드로 강제되지 않으며**,
담당자가 어느 시점에든 이전 결정을 변경하면 시스템이 이를 반영합니다.

```mermaid
flowchart LR
  A["① 교육 선택"] --> B["② 생성 설정 결정"]
  B --> C["③ 구성 계획 확정과<br/>근거 수집"]
  C --> D["④ 생성"]
  D --> E["⑤ 수정"]
  E --> F["⑥ 확정"]
```

1. **교육 선택** — 연간계획에 등록된 교육 후보에서 선택합니다. 계획에 없는 주제를 즉석
   지정하거나, 업로드한 문서를 기반으로 시작하는 경로도 지원합니다. 선택하면 시스템이
   교시별 주제 구성 초안(구성 계획)과 설정 질문 카드를 함께 제시합니다.
2. **생성 설정 결정** — 문서 형태·난이도·분량·시험 구성을 질문 카드로 결정합니다. 답변은
   구성 계획에 반영되며, 분량을 지정하면 그 분량에 담기는 수준으로 교시 주제가
   재정리됩니다.
3. **구성 계획 확정과 근거 수집** — 설정이 반영된 계획을 담당자가 대화로 다듬어 확정하고,
   시스템이 교시별 근거 자료(연간계획·법령·첨부 문서·사내 문서)를 수집합니다. 확정된
   계획이 **이후 모든 작업의 기준**이 됩니다 — [구성 계획](./syllabus.md) 문서에서 상세히
   다룹니다.
4. **생성** — 교육자료(페이지 단위 HTML)를 생성합니다. 시험지는 **기본으로 함께 생성**되며,
   담당자가 제외를 요청한 경우에만 생성하지 않습니다. 요약본은 분량을 지정한 경우,
   설문은 요청한 경우에 생성됩니다.
5. **수정** — 특정 교시·페이지·문항 단위의 수정 요청을 처리합니다. 수정 범위에 해당하는
   부분만 재생성됩니다.
6. **확정** — 최종 산출물 패키지를 구성해 제시합니다. 시험 응시 안내는 백엔드가 발급하는
   응시 링크로 처리됩니다.

## 사용 예시

가상의 교육 "밀폐공간 작업 안전"(생산1팀, 2교시 구성)의 진행 예시입니다. 탭에 진입하면
시스템이 그 팀의 연간계획 교육 후보를 번호 달린 표로 제시합니다 — 예시에서는 다음
목록이 제시되었다고 가정합니다.

| 번호 | 교육 | 계획 시간 | 작성 |
|---|---|---|---|
| 1 | 화학물질 취급 안전 | 4h | 작성됨 |
| 2 | 지게차 작업 안전 | 2h | 미작성 |
| 3 | 밀폐공간 작업 안전 | 4h | 미작성 |

| 담당자 입력 | 시스템 동작 |
|---|---|
| (탭 진입) | 위 교육 후보 목록을 표로 제시 |
| "3번으로 해줘" | 후보 3번 선택, 2교시 구성 계획과 설정 질문 카드 제시 |
| "구성은 알아서 하고, 자료는 쉽게 만들어줘" | 미지정 설정을 기본값으로 채우고 난이도를 조정한 뒤, 교시별 근거를 수집해 계획 확정 |
| "만들어줘" | 교육자료 생성. 실제 페이지 수와 근거 사용 내역을 보고 |
| "2교시에 사고 사례 하나 더 넣어줘" | 2교시만 재생성하고 변경 내역을 정리해 제시 |
| "확정해줘" | 최종 산출물 패키지(자료·시험지) 구성 |

## 산출물

| 산출물 | 형태 | 설명 |
|---|---|---|
| 교육자료 | 페이지 단위 HTML | 세로형 문서 또는 가로형 발표 자료. 수집된 근거의 내용으로 구성되며, 페이지별로 사용한 근거가 기록됨 |
| 요약본 | 페이지 단위 HTML | 교육자료의 압축본. 분량(쪽수 또는 비율)을 지정한 경우에만 생성 |
| 시험지 | 단일 HTML | 시험 구성 카드(문항 수·유형)에 따라 출제. 출제 근거는 수강자에게 전달되는 교육자료 본문 |
| 강의평가 설문 | 단일 HTML | 기본 문항 구성으로 생성. 문항 추가·삭제 지원 |

산출물은 **파일로 저장되지 않고** 응답에 포함되어 화면으로 전달됩니다. 응답에는 해당 턴에
**생성·변경된 산출물만** 포함됩니다 — 이전 턴의 산출물이 반복 노출되지 않습니다.

## 제한 사항

산출물의 저장과 배포, 결재, 시험 응시와 채점, 수료 처리는 **이 탭의 범위 밖**이며 화면과
백엔드가 담당합니다. 범위 밖 요청에는 수행 가능한 범위를 안내하는 응답을 반환하며,
**수행하지 않은 작업을 수행한 것으로 보고하지 않습니다**.
