# 생성 설정과 질문 카드

**질문 카드**는 생성에 필요한 결정을 수집하는 **입력 수단**입니다. 교육 진입 시 카드가
제시되고, 담당자는 보기 중에서 답을 선택합니다. 카드에 답한 뒤에는 **대화로 세부 조정**이
가능합니다. 답변은 바로 [교육자료 구성 계획](./syllabus.md)에 반영되며, 이후의 모든
생성 작업은 **이 계획을 기준으로** 동작합니다.

생성 설정과 구성 계획은 역할이 나뉩니다. 구성 계획이 "무엇을 가르칠 것인가"(교시별 주제
구성과 담당자 요구사항)를 정한다면, 생성 설정은 그 내용을 **"어떤 형태와 방식으로 만들
것인가"**(문서 형태, 생성 단위, 난이도, 분량, 요약본)를 정합니다. 설정 값도 구성 계획 안에 함께
저장되어 하나의 기준을 이룹니다.

## 설정 항목

| 항목 | 결정 내용 |
|---|---|
| 문서 형태 | 세로형 문서 / 가로형 발표 자료 |
| 생성 단위 | 회차 전체를 한 문서로 통합 / 교시별 문서로 분리 |
| 난이도 | 동일 분량 내에서 다룰 내용의 수준 |
| 구성 방식 | 강의식, 문답식, 사례 중심, 체크리스트 등 전개 방식 |
| 분량 | 교시별 목표 쪽수. 교시마다 다르게 지정 가능하며, 사진 상한도 함께 지정 가능 |
| 요약본 | 원본 대비 비율 또는 쪽수. 미지정 시 요약본을 생성하지 않음 |
| 시험 구성 | 문항 수와 유형 — 별도 카드로 제시. [시험과 강의평가](./exam.md)에서 다룸 |

## 카드의 실제 형태

응답 본문에 실리는 설정 묶음의 모양입니다(가공 예시). 답변된 항목은 **확정 값 한 줄**로,
미답 항목은 **질문 카드 블록**으로 표시되고, 기본값 보기에는 ★가 붙습니다. 질문 카드
블록(`:::q`)의 화면 렌더 계약은 [API 계약](../reference/api.md)에서 다룹니다.

```markdown
**[생성 설정]** (2/6 답변됨 — 미답 항목은 ★기본값)

- 문서 형태: **세로형(문서)**
- 분량: **교시당 12쪽**

:::q
Q2. 난이도 — 어떤 깊이로 가르칠까요?
★1) 쉬움(필수만)
2) 중간(필수+부가 조금)
3) 어려움(필수+개념 심화)
왜: 같은 분량이라도 다루는 깊이에 따라 내용 구성이 달라집니다.
:::

번호로 답하시거나 자유롭게 말씀해 주세요.
```

## 동작 규칙

**설정 값은 보기에 제한되지 않습니다.** 카드 답변 후 대화에서 보기 밖의 값("12페이지로
해줘")을 지정하면 그대로 수용됩니다 — 분량·요약본처럼 수치를 받는 항목이 대상입니다.

**답변은 단방향으로 이동합니다.** 카드 답변은 계획으로 옮겨진 뒤 화면 표시·생성 입력·완료
보고가 모두 계획을 읽습니다 — 상세 배경은 [구성 계획](./syllabus.md)의 설계 규칙을
참고하십시오.

**분량 지정은 주제 재정리를 동반합니다.** 교시 분량이 지정되면 해당 분량에 담기는
수준으로 교시 주제를 재정리하는 계획 수정이 이어집니다. 분량만 바꾸고 내용 밀도를
그대로 두면 생성 단계에서 내용이 잘리거나 늘어나기 때문입니다.

**위임 시 기본값이 적용됩니다.** 담당자가 결정을 맡긴 항목은 다음 기본값으로 채워지며,
이후 언제든 개별 변경이 가능합니다.

| 항목 | 기본값 |
|---|---|
| 문서 형태 | 세로형(문서) |
| 생성 단위 | 회차 단위(한 문서) |
| 난이도 | 쉬움(필수만) |
| 구성 방식 | 강의형+사례+QA |
| 분량 | 자동(시스템 기본 분량) |
| 요약본 | 만들지 않음 |
| 시험 구성 | 20문항 — 객관식 10 · 단답형 4 · O/X 4 · 표 기반 O/X 2 |
