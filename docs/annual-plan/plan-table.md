# 연간 계획표 확인

연간 계획표는 확정된 목록과 설문 답으로 조립된 회차 단위 계획이며, 상세 내용 생성 전의
마지막 확인 대상입니다. 담당자가 이 계획표를 승인해야 생성이 시작되고, 승인 전까지는
값과 구성을 얼마든지 조정할 수 있습니다. 승인된 계획표의 회차별 주제 배분이 그대로 생성
범위가 됩니다. 확인받은 것과 만들어지는 것이 같습니다.

## 조립

계획표의 행은 교육의 회차마다 하나씩 만들어집니다. 각 값은 다음 순서로 채워집니다.

1. **교육 데이터**: 법정 시간·주기·학습 주제가 기본 재료가 됩니다. 회차 수는 주기(반기
   주기 교육은 상·하반기 각 1회가 법정 최소)와 시간 분할 답으로 정해집니다.
2. **설문 답**: 시간 기준, 교육방법, 평가방법, 강사의 기본값이 전 교육에 적용됩니다.
3. **과정별 결정**: 대화로 지정한 교육별 예외("정기교육만 반기 2회", 수시 편성 월)가
   기본값 위에 얹힙니다.

연간 시간은 회차에 고르게 나뉘고, 담당자가 회차 시간을 직접 지정한 경우 그 값이
유지됩니다. 여러 회차로 나뉜 교육은 회차마다 다룰 주제가 겹치지 않게 배분되며, 이
배분이 생성 단계의 회차별 범위가 됩니다.

## 실시월 배정

담당자가 직접 지정한 월은 어떤 경우에도 바뀌지 않습니다. 시행월이 빈 회차는 실시월
배정 방식 질문의 답대로 채워집니다. 반기 집중, 연중 분산, 과거 실시월 따르기, 배정하지
않음(공란 유지)의 네 방식입니다.

배정에 자유 발화 요구("10월은 설비점검이라 피해주세요")가 있는 경우, 그 요구가
메모로 남아 있다가 배정 시점에 함께 반영됩니다. 이 경우 배정은 요구와 규칙을 함께 읽는
LLM이 수행하고, 시스템이 결과를 검증합니다. 지정된 월을 건드리거나 범위 밖의 월이
반환되면 그 배정만 버립니다. 배정 호출이 실패하면 시행월은 공란으로 남습니다. 요구를
무시한 배정이 조용히 적용되는 것보다 빈 칸이 낫기 때문이며, 공란은 계획표에서 바로
지정할 수 있습니다.

## 경고

계획 상태에서 파생되는 경고 네 가지가 계획표와 함께 표시됩니다.

| 경고 | 조건 |
|---|---|
| 법정 교육 제외 | 법정 주기제 교육이 계획에서 제외되어 있음 |
| 회차 미달 | 법정 최소 회차(반기 주기는 연 2회)보다 적게 편성됨 |
| 시간 미달·미정 | 회차 시간 합이 법정 기준에 못 미치거나, 시간이 비어 충족을 확인할 수 없음 |
| 기준 미상 | 법정 교육인데 기준 시간을 확인하지 못해 검사할 수 없음 |

경고는 한 번 알리는 알림이 아니라 상태가 유지되는 동안 계속 표시되며, 값을 되돌리면
사라집니다. 어떤 경고도 진행을 차단하지 않습니다.

## 승인과 수정

계획표 화면에서도 값 수정(시행월·시간·강사·교육방법·평가방법), 교육 추가와 제외 복원,
회차 수 변경이 모두 가능합니다. 추가·복원된 교육은 조립과 같은 규칙으로 회차와 값이
완성됩니다. 수정이 반영되면 계획표가 다시 제시되어 확인이 이어집니다.

진행 의사를 밝히면 계획이 승인되고 같은 턴에 생성이 시작됩니다. 다만 그 발화로 법정
제외나 회차 미달 경고가 **새로 생긴** 경우에는 승인을 보류하고 경고를 확인한 뒤 진행
여부를 한 번 더 묻습니다. 경고를 본 적 없이 생성으로 넘어가지 않게 하기 위해서입니다.

계획표가 처음 제시될 때와 수정이 반영된 턴에는 LLM 검토가 함께 수행되어, 담당자가
의도하지 않았을 문제가 있으면 경고와 별도로 짚어 줍니다. 동작 원칙은
[요건 검사](./verification.md)와 같습니다.
