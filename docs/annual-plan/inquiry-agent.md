# 조회 에이전트

조회 에이전트는 정보를 묻는 발화에 답하는 에이전트입니다. 계획을 만들거나 고치지 않고,
[오케스트레이터](./orchestrator.md)가 조회로 판정한 발화만 받습니다. 답한 뒤에는 진행
중이던 단계의 화면이 다시 제시되어 흐름이 유지되며, 다음 단계로 넘기지 않습니다.

## 조회의 기준

수정 중의 질문("지금 계획표 보여줘", "정기교육에는 어떤 내용이 들어가 있어?")의 기준은
**세션이 들고 있는 현재 계획**입니다. 대화로 반영한 값은 화면에서 저장하기 전까지 백엔드
데이터에 없으므로, 백엔드 조회 결과로 현재 값을 판정하지 않습니다. 저장본과 지금 세션의
차이 자체를 물을 때만 둘을 나란히 놓고 아직 저장 전이라는 사실과 함께 설명합니다.
생성된 상세 내용은 회차 단위 전체 텍스트를 돌려주는 조회 도구로 확인하며, 잘라서
보여주지 않습니다.

## 도구

조회 에이전트가 쥐는 도구는 교육 데이터 조회 도구 전부(교육과정·부서·공통코드·연간 계획·
실적)와, 세션에서 생성한 본문이 있을 때 추가되는 본문 조회 도구입니다. 계획을 고치는
도구는 없습니다. 이미 조회한 결과는 세션에 누적되어 다음 턴에 다시 실리므로, 같은 정보를
턴마다 다시 조회하지 않습니다.

| 담당자 입력 | 시스템 동작 |
|---|---|
| "지금 계획표 보여줘" | 세션의 현재 계획표로 답함 |
| "정기교육 법정시간이 몇 시간이야?" | 교육과정 조회 도구로 확인해 답함 |
| "이 교육 작년에도 했어?" | 팀의 실적 조회 도구로 확인해 답함(기록이 없으면 없다고) |
| "특별교육 내용에 뭐가 들어갔어?" | 세션 생성 본문 조회 도구로 해당 회차 전문을 읽고 답함 |

## 답한 뒤

진행 중이던 단계의 화면(설문 카드, 계획표, 되물음)이 다시 제시됩니다. 질문과 변경 요청이
섞인 발화였다면 변경이 아직 반영 전이라는 고지가 함께 붙습니다. 이 재제시는 조회
에이전트가 아니라 그래프 배선의 노드가 수행합니다.
