# 계획 작성 에이전트

계획 작성 에이전트는 승인된 계획표의 회차마다 상세 교육 내용을 만들고, 생성이 끝난 뒤의
수정을 처리하는 에이전트입니다. 생성은 계획표가 승인된 턴에 바로 시작되며, 회차 전체가
병렬로 처리됩니다. 각 회차는 계획표 확인 때 배분된 자기 담당 주제만 다루므로 회차 간
내용이 겹치지 않습니다. 생성 뒤의 수정은 [편집 에이전트](./editor-agent.md)의 공통 규칙을
따르며, 값 수정, 구성 변경, 내용 수정의 세 갈래로 처리됩니다. 저장된 계획을 불러온 경우도
같은 방식으로 수정합니다.

## 생성

### 내용의 구성

회차의 상세 내용은 모듈 목록으로 생성됩니다. 모듈마다 제목, 배분 시간, 학습목표,
교육내용 항목이 있고, 마지막에 정리·평가 모듈이 붙습니다. LLM은 교육 데이터의 학습
주제와 회차 배분 범위 안에서 모듈 내용을 작성하고, 정해진 형식의 텍스트로 조립하는 것은
시스템이 담당합니다. 모듈 시간의 합은 그 회차의 교육시간과 일치하게 만들어집니다.

팀에 위험 특성 정보가 등록되어 있으면 교육 내용에 그 특성이 반영됩니다. 등록이 없으면
그 반영만 생략되고 생성은 정상 진행됩니다.

### 실패의 처리

생성에 실패한 회차는 내용이 빈 채로 남고, 완료 보고에 그 목록이 안내됩니다. 진행은
차단되지 않으며, 담당자는 해당 내용을 직접 보완하거나 다시 생성을 요청할 수 있습니다.
생성이 끝나면 [요건 검사 에이전트](./checker-agent.md)가 이어집니다.

## 생성 후 수정

### 값 수정

시행월, 시간, 강사, 교육방법, 평가방법 같은 행 값의 변경입니다. 반영되면 계획 행에
동기화되고 바뀐 값이 보고됩니다. 시간을 법정 기준 아래로 바꾸는 요청도 반영됩니다.
미달 사실은 경고가 알리고 진행은 담당자의 판단에 맡깁니다.

### 구성 변경

교육 추가, 제외했던 교육의 복원, 회차 수 변경입니다. 구성이 바뀌면 행 목록이 재구성되는데,
**기존 행의 생성된 내용은 보존되고 새로 생긴 회차와 교육만 부분 생성**됩니다. 회차를
2회에서 4회로 늘리면 기존 두 회차의 내용은 그대로 두고 새 두 회차만 만듭니다. 추가·복원된
교육은 계획표 조립과 같은 규칙으로 회차·시간·기본값이 완성됩니다.

### 내용 수정

주제 추가("지게차 안전도 넣어줘"), 삭제, 더 쉽게·간결하게 같은 문체 조정 등
생성된 상세 내용에 대한 요구는 해당 회차의 내용을 같은 생성기로 다시 작성해 반영합니다. 기존 내용이
기준이 되어 요구와 무관한 모듈은 유지되고, 대상은 지목한 회차·교육·전체 중 요구가
가리키는 범위입니다. 재작성에 실패한 회차는 원문이 유지되고 그 사실이 보고됩니다.

생성 전 화면에서 내용 요구를 말하면 그 교육의 메모로 기록해 두고, 내용이 만들어진 뒤
다시 요청해 달라고 안내합니다. 아직 고칠 본문이 없기 때문입니다.

### 미정 값 되물음

생성 후에도 시간이 비어 있는 교육이 있으면 값을 되묻습니다. 대상은 법정 기준이 있는
교육입니다. 기준이 없는 교육의 시간을 공란으로 두기로 한 설문 결정은 존중되어 다시
묻지 않습니다.

## 저장

계획의 저장과 결재는 화면과 백엔드의 책임 범위입니다. 대화에서 저장을 요청하면 화면의
저장 기능을 안내하며, 대화 내용이 백엔드에 저장되지는 않는다는 사실을 함께 알립니다.
