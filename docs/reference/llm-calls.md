# LLM 호출 지도

교육자료 생성 탭 경로의 LLM 호출 전체 목록입니다. 호출은 **두 부류**로 나뉩니다 —
**담당자에게 발화하는 호출**은 전체 대화 이력을 받고, **내부 변환·판정 호출**은 이력
대신 코드가 계산한 사실 전부를 받습니다. 이 구분의 배경은
[설계 원칙](../maintenance/design-principles.md)을 참고하십시오. 연간 교육계획 탭의
호출은 해당 장 문서화와 함께 이 지도에 추가합니다.

## 호출 목록

| 영역 | 호출 | 입력 | 결정하는 것 | 이력 |
|---|---|---|---|---|
| 요청 분류 | 분류 | 진행 상태 요약 + 발화 | 업무 범위 내/밖 판정, 진행 문구 | 전체 |
| 요청 분류 | 거절 안내 | 발화 | 거절 안내문 (도구 미연결) | 전체 |
| 대화 | 도구 호출 루프 | 행동 지침 + 상태 요약 | 도구 선택과 최종 응답 발화 — 탭의 중심 호출 | 전체 |
| 대화 | 시스템 안내문 | 코드가 확정한 사실 목록 | 안내 문장 표현 (사실은 코드가 결정) | 전체 |
| 첨부 | 요지 추출 | 파일명 + 본문 전문 | 파일별 요지 | 없음 |
| 첨부 | 교시 귀속 | 교시 구성 + 파일 본문 | 파일별 배정 교시 | 없음 |
| 계획 | 재료 충분성 판정 | 계획 재료 | 작성 가능 여부, 보강 검색 질의 | 없음 |
| 계획 | 계획 작성 | 재료 + 검색 후보 | 교시 구성 초안 | 없음 |
| 계획 | 수정 재료 판정 | 계획 + 수정 요구 | 재료 충분 여부, 보강 검색 질의 | 없음 |
| 계획 | 수정 적용 | 계획 + 요구 + 근거 | 수정된 계획 전체 | 전체 |
| 근거 | 검색 질의 생성 | 교시 주제·요구사항 | 교시별 검색 질의 | 없음 |
| 근거 | 근거 선별 | 후보 문서 요약·본문 | 채택 문서와 종류 | 없음 |
| 생성 | 스토리라인 작성 | 계획 서술 + 근거 전문 + 요구사항 | 주제 시퀀스 (마무리 주제 포함), 근거·이미지 배정 | 없음 |
| 생성 | 이미지 선택 | 이미지 실물 첨부 | 유지·이동·제외 판정 | 없음 |
| 생성 | 주제별 내용 확장 | 배정 근거 전문 | 주제의 유닛들 | 없음 |
| 생성 | 교시 단위 정리 | 교시 유닛 전체 | 다듬어진 유닛들 | 없음 |
| 생성 | 슬라이드 구성 (가로형만) | 유닛 요약 + 실측 높이 | 페이지 묶음 계획 | 없음 |
| 생성 | 이미지 내용 판독 | 이미지 실물 | 이미지 설명·종류 (캐시됨) | 없음 |
| 요약본 | 압축 작성 | 자료 전문 평문 | 요약본 구성 | 없음 |
| 시험 | 시험 생성 | 자료 본문 + 구성·요구 | 문항 전체 | 없음 |
| 시험 | 문항 교체 | 원 문항 전체 + 지시 | 새 문항 | 없음 |
| 수정 | 범위 판독 | 현재 구성 + 지시 | 수정 단계·대상 | 전체 |
| 수정 | 유닛 재작성 | 대상 유닛 + 지시 | 교체 유닛 | 없음 |
| 수정 | 법정 내용 판정 | 삭제 대상 + 법령 근거 | 법정 여부 (실패 시 법정 간주) | 없음 |
| 공통 | 추천 문구 | 상태 요약 | 다음 발화 추천 목록 | 없음 |

추천 문구 호출은 탭 공용 에이전트의 호출이며, **유일하게 추론 강도 설정을 낮춰** 실행됩니다.

## 프롬프트 파일 규약

프롬프트는 **코드와 동거**합니다 — 각 에이전트 폴더의 `prompts/<작업명>/` 아래
`system.yaml`(행동 지침)과 `user_template.yaml`(입력 틀) 한 쌍이 호출 하나에
대응합니다. 로더는 클래스 상속 순서를 따라 해당 클래스 폴더의 프롬프트를 찾고, 없으면
에이전트 이름 기준 공용 위치로 폴백합니다. **템플릿 변수가 누락되면** 호출 시점에 오류로
차단됩니다.

## 도구 설명 규약

대화 LLM에 노출되는 조회 도구의 설명은 스킬 폴더의 **도구별 Markdown 파일 본문**을
사용합니다. 설명 파일이 없거나 이름이 중복되면 **구성 시점에 오류**가 발생합니다 — 설명
없는 도구가 LLM에 노출되는 것을 막는 장치입니다. 탭 내부에서 정의되는 작업 도구의
설명은 함수 문서화 주석이 사용됩니다.
