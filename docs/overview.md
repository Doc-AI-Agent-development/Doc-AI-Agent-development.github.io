# 개요

교육 담당자가 대화형 인터페이스로 교육 업무 산출물을 생성하는 **AI 에이전트 서비스**입니다.
이 문서는 시스템을 유지보수·확장하는 개발자를 대상으로, 현재 구현 기준의 아키텍처와
인터페이스 계약, 설계 배경을 설명합니다.

## 시스템 구성

사용자 인터페이스는 웹 화면이며, 화면의 모든 대화 요청은 BFF 계층을 거쳐 AI 서비스의
**단일 API**로 전달됩니다. 요청은 탭 식별자에 따라 해당 탭의 처리 그래프로 넘어갑니다.
탭 그래프는 실행마다 체크포인트 DB에서 세션 상태를 복원하고 턴이 끝나면 기록하며,
공유 기반(상태 모델·에이전트 공통 기반·도구 레지스트리·응답 변환)을 통해 외부 자원에
접근합니다. 도식의 **파이프라인**은 하나의 결과물(계획·근거·자료·시험)을 완성하기 위해
정해진 순서로 실행되는 액션(LLM 호출·코드 처리) 시퀀스입니다.

처리 결과는 **응답으로만** 전달됩니다. 산출물의 저장, 결재, 배포, 시험 응시·채점은 화면과
백엔드의 책임 범위입니다.

## 탭 구조

화면의 업무 탭마다 **독립된 처리 그래프**가 하나씩 등록되어 있습니다. 모든 요청에는 대상 탭
식별자가 포함되며, 해당 탭의 그래프가 요청 한 건(**턴**)의 처리를 전담합니다. 탭 식별자가
없는 요청은 입력 오류로 응답합니다. 선언만 되어 있고 아직 구현되지 않은 탭을 호출하면
오류가 아니라 준비 중 안내로 응답합니다.

| 탭 | 기능 | 문서 상태 |
|---|---|---|
| 연간 교육계획 | 팀의 연간 교육 계획 수립·수정 | [연간 교육계획 수립하기](./annual-plan/intro.md) |
| 교육자료 생성 | 개별 교육의 자료·요약본·시험·설문 생성과 수정·확정 | [교육자료 생성하기](./edu-material/intro.md) |
| 교육 이수 결과 관리 | 강의평가 요약과 교육 실적 총평 정리 | 작성 예정 |

## 탭 간 분리와 공유 기반

탭 간에는 **코드 의존이 없습니다**. 대화형 탭(연간 교육계획·교육자료 생성)은 요청 분류를
담당하는 **오케스트레이터**와 프롬프트, 상태 필드를 각자 보유합니다. 조회성 탭(교육 이수 결과 관리)은
오케스트레이터 없이 요청 값으로 분기합니다. 교육자료 생성 탭은 연간 교육계획 탭의 작업 결과를 상태로
전달받지 않으며, 백엔드 조회 API로 저장된 연간 교육계획 데이터를 직접 조회합니다. 대화 세션도
**탭 단위로 분리됩니다** — 하나의 세션이 여러 탭을 오가지 않습니다.

다음 기반 계층은 전체 탭이 공유합니다. 이 계층의 변경은 모든 탭에 영향을 줍니다.

| 공유 기반 | 역할 |
|---|---|
| 상태 모델 | 세션 상태를 담는 단일 모델 (탭별 필드는 분리) |
| 에이전트 공통 기반 | 프롬프트 로더, LLM 호출 관례, 도구 호출 루프 |
| 도구 레지스트리 | 데이터 조회·검색·스토리지 도구를 구성해 각 탭 그래프에 주입 |
| 응답 변환 | 그래프 결과를 화면 응답 계약으로 변환 |
| 턴 동시성 제어 | 세션당 실행 턴을 하나로 제한 |
| 진행 상태 전달 | 처리 중 상태 문구를 화면에 제공 |
