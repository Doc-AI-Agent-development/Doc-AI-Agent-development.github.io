# 확장 체크리스트

새 요소를 추가할 때 수정해야 하는 위치의 전체 목록입니다. 이 시스템의 확장 지점들은
여러 위치가 **한 벌**로 맞물려 있어, **한 곳이라도 누락하면** 오류 없이 내용이 조용히
사라지거나 기능이 동작하지 않습니다.

## 대화 도구 추가

가장 빈번한 확장입니다.

1. 도구 함수를 작업 도구 정의부(`handle_request/agent.py`의 도구 구성 함수) 안에
   정의합니다. **문서화 주석이 LLM에 노출되는 도구 설명**이 됩니다.
2. 동기/비동기 등록 목록에 함수를 추가합니다 — **등록하지 않으면 LLM에 노출되지 않습니다**.
3. 도구 반환 문자열의 **거부 접두 규약**을 지킵니다 — 정해진 접두("…불가:")로 시작하는
   반환만 재시도가 허용되고, 그 외 실패 문구는 성공으로 기록되어 같은 인자의 재호출이
   차단됩니다.
4. 큰 전환을 수행하는 도구라면 **턴당 전환 1회 가드**와의 상호작용을 확인합니다.

## 콘텐츠 유닛 종류 추가

유닛 모델부터 렌더·실측·직렬화까지 한 벌입니다. 하나라도 빠지면 해당 유닛이 **오류 없이
화면에서 빠집니다**.

| 수정 위치 | 내용 |
|---|---|
| `src/schemas/education_content.py` | 유닛 모델 정의와 유닛 합집합 타입 등록 |
| `components/compose.py` | 가로형·세로형 유닛→조각 매핑 **양쪽 모두** |
| `generate_content/deck_text.py` | 평문 직렬화(요약본·시험 입력용) |
| `generate_content/deck.py` | 추정 높이 표(가로·세로)와 페이지 구성용 유닛 요약 |
| 주제 확장 프롬프트(가로·세로) | 새 유닛의 작성 지침 |

## 렌더 조각 추가

조각 파일(`fragments/<방향>/…`)에 메타 주석을 붙여 추가하면 카탈로그에 자동
등록됩니다. 단 카탈로그는 프로세스 시작 시 1회 스캔되므로 **서버 재기동이 필요**하고,
유닛→조각 매핑에 연결되지 않은 조각은 실서비스 경로에서 렌더되지 않습니다.

## 문서 형태(템플릿) 추가

렌더러, 테마 자산(색을 포함한 SVG), 설정 카드 보기, 렌더러 디스패치, 페이지 예산 상수,
실측 폭·CSS 복제본이 한 벌입니다. 특히 실측 모듈의 CSS는 **렌더러 셸 CSS의 복제본**이라
함께 맞춰야 합니다.

## 산출물 종류 추가

상태 필드, 작업공간 보관 목록, 턴 내 상태 복사·델타 키 목록, 산출물 이름 매핑, 응답
변환의 노출 목록과 턴 게이트, 확정 패키지 표, 수정 파이프라인의 대상 집합이 한
벌입니다. 작업공간 보관 목록에서 누락되면 **교육 전환 자체가 실패**합니다.

## 설정 항목 추가

생성 설정 모델, 카드 정의, 카드→계획 반영 규칙, 설정 표시 줄, 계획 렌더의 설정 줄이 한
벌입니다.

## 시험 유형 추가

유형 키 목록, 기본 배분 프로파일, 라벨 매핑, 카드 보기, 도구 인자 계약, 시험지 답란
렌더가 한 벌입니다.

## 설문 질문·보기 수정 (연간 계획 탭)

설문의 질문·보기는 화면 표시와 처리 코드가 한 벌입니다. **보기의 뜻은 처리 코드에
있습니다** — 처리 코드 없이 보기만 추가하면 선택해도 아무 일도 일어나지 않는 보기가
됩니다(오류 없음 — 실제로 그런 보기가 발견되어 제거된 일이 있습니다).

| 수정 위치 | 내용 |
|---|---|
| 질문 정의부(`intake/agent.py`의 질문 템플릿 함수) | 질문 문구·보기·기본값·값 필요 표시 — 화면에 보이는 부분 전체 |
| 계획 범위 답 처리(`intake/agent.py`의 단계 전진부) | 범위 답에 따른 자율 교육 제외와 단계 생략 |
| 시간 답 반영(`planner/agent.py`) | 근로자 분류·감면 답의 기준 시간 조정, 시간 분할 보기→회차 수 변환표 |
| 실시월 배정 갈림(`planner/agent.py` · `schedule_rules.py`) | 배정 방식 보기→배정 규칙 연결 |
| 실행 답 반영(`planner/agent.py`) | 교육방법 적용·평가방법 자동 매핑·강사 기본값 |
| 일괄 생성 답안(`intake/auto.py`) | 운영 답안이 **보기 번호**로 지정됨 — 보기 순서·번호 변경 시 함께 |
| 편집 호출 프롬프트(`editor/prompts/apply/`) | 질문 답 기록 규칙 — 기본값 적용 범위, 값 필요 보기의 되물음, 실시월 요구 메모 |
| 복원·추가 완성(`planner/agent.py`) | 계획표에서 복원·추가된 교육의 빈 칸을 설문 답으로 채우는 경로 |
| 유닛테스트(`tests/unit/test_agents.py`) | 질문 문구·보기 라벨·기본값을 고정하는 단언 다수 |

보기 일부는 정의부에 고정되어 있지 않고 실행 시점에 만들어집니다 — 교육방법 보기는
백엔드 표준 코드 목록에서, 강사 보기는 부서 담당자 이름으로 조립되고, 시간이 확인되지
않는 교육의 처리 질문은 결측 검사가 추가합니다. 이런 보기의 문구는 정의부에서 바꿀 수
없습니다.

## 실시월 배정 규칙 수정 (연간 계획 탭)

배정 규칙의 문구는 상수 하나가 정본이며 배정 호출과 편집 호출 두 프롬프트에 주입됩니다.
버튼 답만으로 진행된 경우에는 같은 규칙을 **코드가 직접 수행**하므로, 문구를 바꾸면 규칙
코드의 동작과 편집 프롬프트의 화면 한정 조정 문장을 함께
맞춥니다([프롬프트와 설정 수정](./prompts-and-settings.md)).

## 탭 추가

탭 그래프 빌더 등록, 탭 메타(라벨·준비 상태), 진행 상태 라벨 등록이 필요합니다.
