# 기능 추가 가이드

새 요소를 추가할 때 함께 수정해야 하는 위치의 목록입니다. 이 시스템의 확장 지점은 여러
위치가 **한 벌로 맞물려** 있어, **한 곳이라도 누락하면** 오류 없이 내용이 조용히 사라지거나
기능이 동작하지 않습니다. 절은 탭 공통과 탭별로 나뉘며, 탭 안에서는 대화 계층부터
산출물 내부 순서로 정렬되어 있습니다. 추가하려는 요소의 절을 찾아 표의 위치를 전부
수정한 뒤, [테스트](../testing.md)의 검증 기준대로 확인하십시오.

## 공통

### 업무 영역(탭) 추가

연간 교육계획 수립, 교육자료 생성 같은 상위 업무 영역은 화면의 탭과 1:1로 대응하는
**대화형 탭**으로 추가됩니다. 탭별 그래프 구조는 [요청 처리
흐름](../concepts/request-lifecycle.md)에서 다룹니다.

| 수정 위치 | 내용 |
|---|---|
| `src/graphs/tabs/` | 탭 그래프 빌더와 탭 메타(라벨·준비 상태) 등록 — 탭 목록 API는 이 등록을 그대로 돌려줌 |
| `src/api/progress.py` | 진행 상태 라벨 등록 |

## 교육자료 생성 탭

### 대화 도구 추가

담당자 발화로 실행되는 기능은 대화 LLM에 노출되는 도구로 추가합니다. 도구 호출 루프의
동작은 [요청 처리 흐름](../concepts/request-lifecycle.md)에서 다룹니다.

1. 도구 함수를 작업 도구 정의부(`src/tabs/edu_material/handle_request/agent.py`의 도구
   구성 함수) 안에 정의합니다. **문서화 주석이 LLM에 노출되는 도구 설명**이 됩니다.
2. 같은 파일의 동기/비동기 등록 목록에 함수를 추가합니다 — **등록하지 않으면 LLM에
   노출되지 않습니다**.
3. 도구 반환 문자열의 **거부 접두 규약**을 지킵니다 — 정해진 접두("…불가:")로 시작하는
   반환만 재시도가 허용되고, 그 외 실패 문구는 성공으로 기록되어 같은 인자의 재호출이
   차단됩니다.
4. 큰 전환을 수행하는 도구라면 **턴당 전환 1회 가드**와의 상호작용을 확인합니다.

### 설정 항목(질문 카드) 추가

질문 카드로 받는 생성 설정을 추가하는 작업입니다([생성 설정과 질문
카드](../edu-material/settings.md) 참조). 카드 답은 구성 계획으로 옮겨진 뒤 계획에서만
읽습니다.

| 수정 위치 | 내용 |
|---|---|
| `src/schemas/syllabus.py` | 생성 설정 모델의 필드 |
| `handle_request/agent.py` | 카드 정의와 설정 항목·카드 번호 계약 |
| `syllabus/settings_sync.py` | 카드 답을 계획에 반영하는 규칙 |
| `syllabus/render_block.py` | 계획 화면의 설정 표시 줄 |

### 산출물 종류 추가

교육자료·시험지처럼 담당자에게 전달되는 산출물을 추가하는 작업입니다. 산출물의
저장 구조는 [상태와 세션](../concepts/state.md)에서, 응답 노출은 [API
계약](../reference/api.md)에서 다룹니다.

| 수정 위치 | 내용 |
|---|---|
| `src/schemas/state.py` | 상태 필드 |
| `handle_request/workspace.py` | 작업공간 보관 필드 목록 — 누락하면 **교육 전환 자체가 실패**합니다 |
| `handle_request/agent.py` | 턴 내 상태 복사·델타 키 목록 |
| `src/api/converters.py` | 산출물 이름 매핑, 응답 노출 목록과 턴 게이트 |
| `handle_request/finalize.py` | 확정 패키지 표 |
| `pipelines/revise_content/agent.py` | 수정 대상 집합 |

### 문서 형태(템플릿) 추가

세로형 문서·가로형 발표 자료 같은 교육자료의 문서 형태를 추가하는 작업입니다([교육자료
생성](../edu-material/generation.md)의 문서 형태 절 참조).

| 수정 위치 | 내용 |
|---|---|
| `generate_content/deck_render*.py` | 새 형태의 렌더러와 테마 자산(색을 포함한 SVG) |
| `handle_request/agent.py` | 문서 형태 카드의 보기 추가 |
| `generate_content/deck.py` | 렌더러 디스패치와 페이지 예산 상수 |
| `components/measure.py` | 실측 폭·CSS — **렌더러 셸 CSS의 복제본**이라 함께 맞춥니다 |

### 콘텐츠 유닛 종류 추가

유닛은 교육자료 페이지를 구성하는 내용 최소 단위이며, 타입이 곧 화면 컴포넌트를
결정합니다([교육자료 생성](../edu-material/generation.md)의 파이프라인 참조). 유닛
모델부터 렌더·실측·직렬화까지 한 벌이고, 하나라도 빠지면 해당 유닛이 **오류 없이
화면에서 빠집니다**.

| 수정 위치 | 내용 |
|---|---|
| `src/schemas/education_content.py` | 유닛 모델 정의와 유닛 합집합 타입 등록 |
| `components/compose.py` | 가로형·세로형 유닛→조각 매핑 **양쪽 모두** |
| `generate_content/deck_text.py` | 평문 직렬화(요약본·시험 입력용) |
| `generate_content/deck.py` | 추정 높이 표(가로·세로)와 페이지 구성용 유닛 요약 |
| 주제 확장 프롬프트(가로·세로) | 새 유닛의 작성 지침 |

### 렌더 조각 추가

렌더 조각은 유닛을 화면 HTML로 그리는 부품입니다([교육자료
생성](../edu-material/generation.md)의 코드 참조 표 — 조각 카탈로그). 조각
파일(`fragments/<방향>/…`)에 메타 주석을 붙여 추가하면 카탈로그에 자동 등록됩니다. 단
카탈로그는 프로세스 시작 시 1회 스캔되므로 **서버 재기동이 필요**하고, 유닛→조각
매핑(`components/compose.py`)에 연결되지 않은 조각은 실서비스 경로에서 렌더되지
않습니다.

### 시험 유형 추가

시험 문항 유형을 추가하는 작업입니다([시험과 강의평가](../edu-material/exam.md) 참조).

| 수정 위치 | 내용 |
|---|---|
| `src/schemas/exam.py` | 유형 키와 문항 구조(유형별 슬롯), 시험 구성의 기본 배분 |
| `handle_request/exam_setup.py` | 유형 라벨 매핑과 구성 값 조립 |
| `handle_request/agent.py` | 시험 구성 카드의 보기와 도구 인자 계약 |
| `pipelines/generate_exam/paper.py` | 유형별 답란 렌더 |

## 연간 교육계획 탭

### 설문 질문·보기 수정

설문 질문과 보기를 고치는 작업입니다([설문과 질문 카드](../annual-plan/questions.md)
참조). 질문·보기는 화면 표시와 처리 코드가 한 벌입니다 — **보기의 뜻은 처리 코드에
있으므로**, 처리 코드 없이 보기만 추가하면 선택해도 아무 일도 일어나지 않는 보기가
됩니다(오류 없음 — 실제로 그런 보기가 발견되어 제거된 일이 있습니다).

| 수정 위치 | 내용 |
|---|---|
| `intake/agent.py` | 질문 문구·보기·기본값·값 필요 표시(화면에 보이는 부분 전체)와, 계획 범위 답에 따른 자율 교육 제외·단계 생략 |
| `plan_table/agent.py` | 답을 실제 값으로 옮기는 곳. 근로자 분류·감면 답의 기준 시간 조정, 시간 분할 보기의 회차 수 변환표, 교육방법·평가방법·강사 적용, 복원·추가된 교육의 빈 칸 채움 |
| `plan_table/schedule_rules.py` | 실시월 배정 방식 보기와 배정 규칙의 연결 |
| `intake/auto.py` | 일괄 생성의 운영 답안이 **보기 번호**로 지정됨 — 보기 순서·번호가 바뀌면 함께 |
| `editor/prompts/apply/` | 질문 답 기록 규칙 — 기본값 적용 범위, 값 필요 보기의 되물음, 실시월 요구 메모 |

고친 뒤 `tests/unit/test_agents.py`를 확인합니다. 질문 문구·보기 라벨·기본값을 고정하는
단언이 여럿 있어 함께 손봐야 합니다.

보기 일부는 정의부에 고정되어 있지 않고 실행 시점에 만들어집니다 — 교육방법 보기는
백엔드 표준 코드 목록에서, 강사 보기는 부서 담당자 이름으로 조립되고, 시간이 확인되지
않는 교육의 처리 질문은 결측 검사가 추가합니다. 이런 보기의 문구는 정의부에서 바꿀 수
없습니다.

### 실시월 배정 규칙 수정

배정 규칙의 문구는 상수 하나가 정본이며 배정 호출과 편집 호출 두 프롬프트에
주입됩니다([연간 계획표 확인](../annual-plan/plan-table.md) 참조). 버튼 답만으로 진행된
경우에는 같은 규칙을 **코드가 직접 수행**하므로, 문구를 바꾸면 규칙 코드의 동작과 편집
프롬프트의 화면 한정 조정 문장을 함께
맞춥니다([프롬프트와 설정 수정](./prompts-and-settings.md)).
