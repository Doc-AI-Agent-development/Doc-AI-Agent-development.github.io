# 진단과 관측

동작 이상이 관찰될 때 **증상에서 원인으로** 접근하는 진단표와, 시스템이 제공하는 관측·복구
수단입니다.

## 증상별 진단

| 증상 | 유력 원인 | 확인 방법 |
|---|---|---|
| 페이지가 넘치거나 유닛 하나짜리 페이지가 많음 | Chrome 미설치로 실측이 추정 폴백으로 동작 | 실행 환경에서 Chrome 실행 파일 존재 확인 |
| 교육 후보 표가 비어 있음 | 백엔드 교육 데이터 API 미가동 또는 해당 팀의 계획 없음 | 백엔드 API 상태와 응답 확인 |
| 사내 문서 근거가 수집되지 않고 진행됨 | 검색 엔진 미가동 — 검색 없이 계속하는 축소 동작 | 검색 엔진 상태 확인. 담당자 안내에 검색 불가 사실이 포함되었는지 확인 |
| 첨부를 읽지 못했다는 안내 반복 | 스토리지 서비스 미가동 또는 파일 경로 불일치 | 스토리지 API 상태·파일 목록 확인. 일시 실패는 다음 턴에 자동 재시도 |
| 생성 내용 품질 이상(특정 교시) | 근거 부족 또는 생성 단계 실패 폴백 | 생성 중간 산출물 덤프 설정을 켜고 재현 — 교시별 단계 산출물이 파일로 남음 |
| 이미지가 낡은 정보로 배치됨 | 문서 이미지 캐시(프로세스 수명·파일 캐시) | 서비스 재기동, 판독 캐시 파일 정리 ([불변식](./invariants.md) 참조) |
| 응답이 오지 않거나 턴이 취소됨 | 동일 세션의 요청 겹침 — 나중 요청이 우선 | 취소 오류 코드 확인. 정상 동작임 |
| 문서함에 문서를 추가했는데 검색되지 않음 | 색인은 오프라인 배치 — 알림 API는 스텁 | 배치 색인 실행 후 재기동 ([외부 의존](../reference/external-services.md)의 코퍼스 갱신 절차) |

## 관측 수단

| 수단 | 내용 |
|---|---|
| 진행 상태 폴링 | 처리 중 턴의 단계 문구를 API로 조회 ([API 계약](../reference/api.md)) |
| 토큰 사용 로그 | 모든 LLM 호출의 토큰 사용량이 호출 단위로 기록됨 — 비용·호출 폭주 확인 |
| 생성 중간 산출물 덤프 | 설정을 켜면 교시별 파이프라인 중간 결과(전개 구조·유닛·정리 결과)가 파일로 남음 — 생성 품질 진단의 기본 도구 |
| 체크포인트 조회 | 체크포인트 DB 파일을 열어 특정 세션의 저장 상태를 직접 확인 가능 (읽기만 할 것) |

## 복구 수단

| 수단 | 동작 | 유의 |
|---|---|---|
| 턴 취소 API | 진행 중 턴을 중단하고 체크포인트를 턴 시작 시점으로 되돌림 | 진행 중 턴이 없으면 무동작 성공 |
| 세션 삭제 API | 세션 상태 전체와 첨부 이미지 캐시를 제거 | 되돌릴 수 없음 |
| 새 요청 전송 | 겹침 가드가 기존 턴을 취소하고 새 턴을 시작 | 앞 턴의 작업은 저장되지 않음 |
