# 기능 찾기

연간 교육계획 탭의 기능을 고치려 할 때 **어느 에이전트의 어느 자리를 손대는지** 찾는
색인입니다. 행은 담당자가 화면에서 보는 기능이고, 링크는 그 기능을 고치는 방법이 적힌
에이전트 항목입니다. 각 에이전트 항목에는 고칠 자리(파일)·함께 봐야 하는 곳·테스트 방법이
있습니다. 기능이 어떻게 동작하는지는 [연간 교육계획 수립하기](../../annual-plan/intro.md)
장이, 이 묶음은 어디를 고치는지가 주제입니다.

고칠 자리는 네 층 중 하나입니다. 층이 다르면 고치는 방법과 테스트 방법이 다릅니다.

| 층 | 무엇 | 반영 | 테스트 |
|---|---|---|---|
| 프롬프트 | LLM의 판단·말투를 가르치는 글(에이전트 폴더의 프롬프트 파일) | 저장하면 다음 호출부터 | 실제 LLM으로 대화를 돌려 확인(모의 LLM 단위 테스트로는 검증되지 않음) |
| 코드 | 결정론 규칙·렌더·조립 | 서버 재기동 | 단위 테스트 |
| 설정 | 환경 변수와 운영 설정 파일 | 서버 재기동 | 값을 바꿔 실측 |
| 도구 설명 | LLM이 읽는 조회 도구 안내문(마크다운) | 서버 재기동 | 도구 목록 단위 테스트 + 실제 대화 |

테스트와 스모크의 종류는 [테스트](../../testing.md)의 연간 교육계획 탭 절에 있습니다.
