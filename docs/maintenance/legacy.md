# 과도기 흔적

저장소에 남아 있으나 **새 코드가 기대어서는 안 되는 것들**의 목록입니다. 구조 개편 과정의
흔적이며, 각각 왜 남아 있는지와 취급 방법을 적습니다.

| 항목 | 위치 | 상태·취급 |
|---|---|---|
| 자동 요건 점검(4축) | 상태 필드 `verification` | 폐기됨 — 채우는 코드가 없고 확정 게이트의 방어 코드만 남음. 점검 결과가 있다고 가정한 발화·안내를 새로 만들지 말 것 |
| 진행 단계 값 일부 | 진행 시트의 단계 값 | "준비 완료" 단계는 어떤 코드도 설정하지 않는 사문 값 |
| 구성 방식 전개 하드코딩 | 작업 에이전트의 전개표 상수 | 임시물로 명시됨 — 제거 예정. 생성 파이프라인이 역방향으로 가져다 쓰므로 제거 시 함께 정리 |
| 시뮬레이션 전용 렌더 모듈 | `pipelines/generate_content/components/render.py` | 본선 미사용, 파일 머리에 삭제 예정 명시. 유일한 사용처는 개발용 시뮬레이션 서버 |
| 자유 블록 조립 계약 | `components/compose.py`의 앞부분 클래스들 | 본선·테스트 어디에서도 호출되지 않음 — 삭제 예정 표시가 붙어 있음. 새 코드가 이 계약에 기대지 말 것 |
| 가로형 그림 크기 표의 미사용 항목 | 가로형 렌더러의 크기 표 | 소형 항목은 참조 없음. 중형 항목은 표시 단계 누락 시의 방어 기본값으로만 살아 있음 |
| 과거 에이전트 디렉터리 | `src/agents/` 아래 내용 없는 폴더들 | 코드가 탭 구조로 이동하고 남은 로컬 캐시 잔재 — 저장소에는 없음. 살아 있는 것은 공통 기반, 추천 문구, 설문·평가 에이전트뿐 (패키지 문서화 주석에 명시) |
| 문서함 알림 API | `POST /agent/documents/uploaded` / `deleted` | 계약만 존재하는 스텁 — 재색인 미구현. 응답의 재색인 여부 필드는 항상 거짓 |
| 진행 시트의 보류 필드 | 진행 시트 구조 | 레거시·미사용으로 명시됨 |

이 목록의 항목을 정리(삭제)하는 작업은 해당 항목을 참조하는 방어 코드·주석까지 함께
정리해야 완료됩니다. 정리 전까지는 **새 기능의 근거로 삼지 않는 것**이 규칙입니다.
